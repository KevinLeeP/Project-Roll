<h1>Project Roll </h1>
<p1>Project Roll is a spherical robot that achieves omni-directional movement using omni-wheels and a hamster ball drive mechanism. The robot features a custom Smart Power Distribution Board made in KiCAD that centralizes power management and connections between sensors, motors, and ESP-32 MCU onto one board. The software written in C++ is currently a work in progress.</p1>
